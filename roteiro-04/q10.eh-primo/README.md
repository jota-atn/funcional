# É primo

Em Python, crie o predicado `eh_primo(n)` que determina se o
número `n` é primo ou não. Use a seguinte definição, para
implementação: "_um inteiro positivo N é primo se seus únicos
divisores são 1 e N_" (por definição, 1 não é primo).

IMPORTANTE: Naturalmente, você deve usar o estilo funcional para
programar esta função! Não use qualquer loop while ou for e
prefira o código mais declarativo possível (list comprehensions
e generatores vale usar).

1. Não se preocupe NADA com eficiência nesta questão. Na próxima
   abordaremos apenas esse aspecto. Neste exercício, escreva o
   código de forma declarativa, fazendo-o refletir da forma mais
   clara possível a especificação.

2. Como a ideia é usar a definição dada como guia para codificar,
   crie uma função `divisores` que retorne os fatores de um
   número. Mais uma vez, lembre que código declarativo tende a
   representar bem as especificações.
