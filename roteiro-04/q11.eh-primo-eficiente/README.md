# É primo eficiente

Faça uma cópia de sua solução pra questão anterior. Agora que
você está convencido de que funciona corretamente, é
chegada a hora de tornar o código mais eficiente.

Comece pelo óbvio, se é que você já não o fez na solução
anterior: se seu código itera até o próprio número N procurando
divisores, lembre que você pode evitar isso, iterando apenas até
a raiz de N.
