# Roteiro 01

## Atividade 1

Usando o presenterm `pt intro-a-clojure.md`, leia a introdução
prática de como escrever código em Clojure, para quem sabe
Python.

Sugestão: usando o tmux, rode o presenterm com os slides e em
outra janela, experimente o uso de Clojure.

## Atividade 2

Leia o arquivo `eq2.py` fornecido. No arquivo `eq2.clj` crie o
programa interativo equivalente em Clojure. Você não precisa projetar o
programa. Apenas mantenha o _design_ do programa Python fornecido
(mesmas funções, mesma lógica geral). A ideia é apenas treinar o
básico de Lisp e Clojure.

## Atividade 3

Escreva outro programa interativo em Clojure, chamado `imc.clj` que apenas
lê a altura e o peso do usuário e imprime a classificação do
usuário quanto a seu IMC: 
- abaixo de 18.5: "Abaixo do peso"
- abaixo de 25: "Peso normal"
- abaixo de 30: "Sobrepeso"
- abaixo de 35: "Obesidade grau I"
- abaixo de 40: "Obesidade grau II"
- acima: "Obesidade grau III"
