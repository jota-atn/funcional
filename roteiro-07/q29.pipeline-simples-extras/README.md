# Pipeline simples

Comece copiando sua solução para a atividade anterior
(q28.pipeline-simples) para este diretório. Atualize a função
`processa` para que formate o resultado em 3 casas decimais (o
resultado passará a ser uma string, naturalmente). Em seguida,
adicione a função `processa_floats(linhas: list[str])` que recebe
uma lista de strings e que retorna uma lista com cada um dos
dados que tiverem sido processados com sucesso das linhas
recebidas.
