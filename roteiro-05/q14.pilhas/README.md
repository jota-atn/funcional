# Implementação de Pilhas sobre Listas

Crie o arquivo `pilhas.py` e nele implemente o tipo Pilha
especificado na questão anterior. Nesta implementação, use listas
Python como representação interna. Inclua contratos em todas as
operações, ao estilo DbC (ou seja, na forma de pré-condições).

> Testes: para rodar os testes básicos, espera-se apenas poder
> copiar o arquivo `spec-pilhas.py` do diretório da questão
> anterior para o diretório `q2` e, em seguida, executá-lo
> diretamente com `python3 spec-pilhas.py`. Como ele deve importar
> as operações do módulo `pilhas.py`, os testes devem funcionar
> perfeitamente. Lembre, quando eu fizer os testes, farei a cópia
> primeiro. Assim, não adianta fazer ajustes ou customizações no
> arquivo de testes. Ele deve funcionar exatamente como está no
> diretório da questão anterior.
