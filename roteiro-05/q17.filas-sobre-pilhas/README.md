# Implementação de Filas sobre Pilhas

Copie para este diretório o arquivo `pilhas.py` que você criou na
atividade de implementação de pilhas sobre listas. Crie o arquivo
`filas.py` e nele implemente mais uma vez o tipo Fila
especificado anteriormente. Nesta implementação, contudo, você
deve usar apenas pilhas proporcionadas por sua própria
implementação. Inclua contratos em todas as operações, ao estilo
DbC (ou seja, na forma de pré-condições).

> Testes: para rodar os testes básicos, espera-se apenas poder
> copiar o arquivo `spec-filas.py` do diretório da questão
> anterior para este diretório e, em seguida, executá-lo
> diretamente com `python3 spec-filas.py`. Como ele deve importar
> as operações do módulo `filas.py`, os testes devem funcionar
> perfeitamente. Lembre, quando eu fizer os testes, farei a cópia
> primeiro. Assim, não adianta fazer ajustes ou customizações no
> arquivo de testes. Ele deve funcionar exatamente como está no
> diretório da questão anterior.
