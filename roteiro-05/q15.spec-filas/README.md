# Especificação do Tipo Fila

No arquivo `spec-filas.py` especifique o tipo Fila em Python,
usando apenas testes simples (asserts) sobre as operações
planejadas para o tipo. Tente implementar o mínimo possível de
operações que permita caracterizar plenamente o tipo. Inclua
especificações para os construtor(es) e seletor(es) que forem
necessários também. IMPORTANTE: o script deve importar o módulo
`filas` com o comando `from filas import *` (você pode preferir
importar explicitamente cada função e/ou objeto, como é a prática
recomendável). Isso permitirá você rodar os testes das questões
seguintes.

> Dica 1: se alguma operação pode ser implementada usando
> exclusivamente as demais operações e sem acessar a
> representação interna (a estrutura de dados usada para
> armazenar os dados do valor), então a operação não é uma das
> primitivas na sua implementação.

> Dica 2: a próxima atividade pede que você implemente o tipo
> fila e que você use sua resposta a esta atividade para testar
> a solução da outra.
